# 资料编辑国家、语言目录更新

在 `dev` 延续已确认的资料编辑设计，保持原有字段和保存接口。

## 交互

- 国家/地区、国籍、两项期望国家、两项语言使用可搜索目录弹层。国旗展示在国家文字前，语言不绑定单个国家。
- 国家来自 ISO 3166-1 的 249 个国家及地区。语言来自 ISO 639-3 当前表的 7,923 个语言条目，包含宏语言、现存及历史语言、手语、人工语言；并非 7,923 种现存口语。
- 国家六语名称齐全。语言使用已有 CLDR 译名，无译名时保留官方英文名称。支持代码、官方英文、六语名称和既有常用名称搜索。
- 已有内容按原文固定展示，点击可清空；选择项再次点击取消。选中不带勾，确认按钮仅提交到当前编辑分组草稿，取消和系统返回不提交本层变动。
- 每批渲染 60 项，可搜索或继续加载。采用现有 240ms 上滑/下滑弹层，关闭动画后卸载，保留减少动效偏好。
- “一句话签名”统一改为“签名”，繁体为“簽名”。
- 提交仅包含文字，不含国旗或 ISO 代码；不改旧值语言，不增加后端或数据库改动。

数据来源、版本、生成方式及授权见 [目录来源](../../profile-catalog-sources.md)。
