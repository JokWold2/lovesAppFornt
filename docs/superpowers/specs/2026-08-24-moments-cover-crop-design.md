# 朋友圈封面裁切与展开设计

## 目标

让用户在上传朋友圈顶部封面前确认展示区域；封面在轮播中以裁切后的图片铺满显示，点击当前封面可查看完整裁切图，关闭后回到同一张轮播页并恢复自动播放。

支持微信小程序、iOS App 与 Android App。下方照片展示与后端 `profiles.photos` 数据结构不在本次改动范围内。

## 数据与接口

- 继续使用 `uni.chooseImage` 选择本地图片。
- 裁切组件通过 Canvas 输出一张新的临时图片；该图片作为唯一上传文件交给现有 `uploadProfilePhotosApi`。
- 后端继续只保存 `photos` URL 数组，不新增裁切坐标或字段。
- 资料加载与本地缓存继续使用服务端返回的 `photos`，因此重新进入页面后的展示与用户确认的裁切结果一致。

## 前端组件

新增可复用的 `CoverCropper` 组件，职责仅限于本地临时图片裁切：

- 固定朋友圈封面比例的可视裁切框。
- 图片初始等比缩放到覆盖裁切框；支持单指拖动和双指缩放。
- 显示取消、完成操作。取消不改动页面和服务器数据；完成时 Canvas 导出裁切图片并向父页面发出临时文件路径。
- Canvas 或图片读取失败时展示提示且保持在裁切层，用户可以取消后重新选择。

`myLifeShow.vue` 保留上传、轮播与资料同步职责：

- 选择一张图片后显示 `CoverCropper`；完成裁切后才显示上传加载状态并调用现有上传 API。
- 本次选择固定一次上传一张，以确保每张封面都有单独的裁切确认。
- 上传成功后以服务端返回数据刷新 `profilePhotos`，并跳到新上传图片所在页。

## 轮播与展开状态

页面维护 `currentCoverIndex`、`coverExpanded` 两个状态：

- 常态：`swiper` 仅在图片多于一张时自动播放；`change` 事件更新当前页。
- 点击封面：将 `coverExpanded` 设为真，关闭 `swiper` 自动播放并使用全屏遮罩展示当前图片；图片保持完整比例，不换页。
- 点击遮罩空白处或关闭按钮：关闭展开层，将 `swiper` 的 `current` 设置回 `currentCoverIndex`，恢复自动播放。
- 展开层点击图片本身不关闭，避免用户查看图片时误收起。

## 样式与可访问性

- 常态封面使用 `aspectFill`，显示用户裁切后的结果，不出现灰底留白。
- 展开态采用深色遮罩和 `aspectFit`，完整展示当前裁切图；不覆盖头像/资料信息。
- 裁切确认层和展开层均覆盖安全区，操作按钮留出安全底部间距。
- 所有触控操作使用 uni-app 支持的事件，避免依赖浏览器专有 API。

## 验证

- 自动测试覆盖：裁切组件存在固定裁切框与 Canvas 导出契约；选择图片先进入裁切层；上传只接受裁切后的路径；展开暂停轮播；收起回到当前页并恢复轮播。
- 手工回归：微信开发者工具、小程序真机、iOS、Android 分别验证选择、拖动、缩放、取消、完成、上传、展开及收起流程。
