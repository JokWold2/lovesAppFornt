# 拍卖详情页设计

## 目标

从首页的 `Auctionactivity.vue` 打开拍品详情。页面以 `#ffce00` 为品牌色，展示拍卖状态、拍品信息和出价记录；“立即出价”在本地模拟成功后，立刻更新价格与记录列表。页面结构与后端接口解耦，后续可替换为真实接口而不改页面组件。

## 页面与导航

- 新建页面：`pages/index/auctionDetail/auctionDetail.vue`。
- 在 `pages.json` 注册，标题为“拍品详情”。
- `Auctionactivity.vue` 的 `openDetail(item)` 使用 `uni.navigateTo` 跳转到 `/pages/index/auctionDetail/auctionDetail?id=${item.id}`。
- 详情页从路由参数 `id` 获取拍品资料；无效 ID 时显示空状态和返回按钮。

## 数据边界

新增 `api/auction.js`，详情页只依赖以下稳定的方法和返回结构：

```js
getAuctionDetail(id) => Promise<{ auction, bidRecords }>
placeBid(id, { userId, userName, avatarUrl }) => Promise<{
  auction: { id, currentPrice, bidCount, ... },
  bidRecord: { id, userId, userName, avatarUrl, amount, bidAt }
}>
```

当前实现使用本地 mock 拍品及 `uni` 本地存储。接口方法内部负责：

- 初始化各拍品的默认价格、结束时间、图集、参数和初始出价记录。
- 使用拍品 ID 作为存储键保存出价后的 `currentPrice`、`bidCount` 与 `bidRecords`。
- 按 `bidAt` 降序返回出价记录。
- 以拍品配置中的 `bidStep` 作为每次模拟出价的加价额。

未来接后端时只替换 `api/auction.js` 的内部实现为请求方法；详情页和首页调用方式不变。

## 详情页 UI

- 顶部金色状态条：显示“拍卖中 / 即将开始 / 已结束”和实时倒计时。
- 拍品图集：可左右滑动，底部显示页码指示器。
- 价格区：拍品编号、名称、当前价、出价次数、提醒按钮。
- 保障与规则区：当面验货、邮寄到付、保留价、起拍价、佣金、竞价阶梯。
- 资料区：年代、尺寸、款识、铃印、品相、作者、质地形式；后接交易流程 01–05。
- 出价记录区：`scroll-view` 固定高度，记录按最新时间置顶；每条包含头像、姓名、出价金额、相对时间（刚刚 / N 分钟前 / N 小时前 / N 天前）。
- 底部固定操作栏：联系客服、参拍提醒、代理出价，以及 `#ffce00` 的“立即出价”。

## 模拟出价规则

- 仅“拍卖中”拍品可出价；其他状态提示原因且不写入数据。
- 点击“立即出价”后，金额增加 `bidStep`，次数加一。
- 生成当前用户的记录，将 `bidAt` 设为当前时间并插入列表顶部。
- 更新写入本地存储；页面显示成功提示。
- 返回首页并重新进入拍卖组件时，首页通过 `getAuctionList`（同一数据模块）读取缓存价格，以同步展示已更新的价格与次数。

## 错误与边界

- 路由缺少或不存在 `id`：不访问数据，展示“拍品不存在”。
- 本地缓存 JSON 损坏：丢弃该条缓存并使用默认 mock 数据。
- 已结束、预展或未开始拍品：保留详情查看，但禁用模拟出价。
- 单张图片时隐藏第二页指示；无封面时显示占位底色。

## 验收标准

1. 点击首页任意拍品卡片或轮播图可打开对应详情页。
2. 详情页主色为 `#ffce00`，并包括图集、倒计时、规则、资料、流程、固定操作栏与可滚动出价记录。
3. 出价记录按最新时间降序，包含头像、姓名、金额和相对时间。
4. 对“拍卖中”拍品点击立即出价，价格、次数、记录会立即更新；返回首页后仍可看到更新值。
5. `auctionDetail.vue` 不直接访问 `uni` 存储，也不直接依赖 mock 数据；数据均从 `api/auction.js` 获取。
